# 饭费管理系统

按月统计学生 / 员工的订餐费用，支持 Excel 名单导入与核算表导出。
纯 Python + Tkinter，无需安装额外界面库。

## 运行

用 [uv](https://docs.astral.sh/uv/) 管理环境，无需手动建虚拟环境：

```bat
uv sync                           :: 安装依赖（openpyxl + pyinstaller）
uv run fee_app.py                 :: 打开空白工程
uv run fee_app.py 某工程.cfee      :: 直接打开指定工程
uv run fee_app.py --help           :: 查看命令行用法
```

也可以直接双击安装后的 `FeeMan.exe`，或双击 `.cfee` 工程文件（安装时会关联）。

## 文件

| 文件 | 说明 |
| --- | --- |
| `fee_core.py` | 核心模型层：工程读写、身份证校验、费用核算、Excel 导入导出，无界面代码，可单独测试 |
| `fee_app.py` | Tkinter 图形界面 |
| `pyproject.toml` / `uv.lock` | 依赖声明与锁定 |
| `fee_app.spec` | PyInstaller 打包配置 |
| `installer.iss` | Inno Setup 安装脚本（含 `.cfee` 文件关联） |
| `build.ps1` | 一键构建：同步依赖 → 打包 → 生成安装包 |
| `assets/app.ico` | 程序图标 |

## 构建与打包

```powershell
# 一条命令完成全部：uv sync → PyInstaller → Inno Setup
powershell -ExecutionPolicy Bypass -File build.ps1

# 可选参数
powershell -ExecutionPolicy Bypass -File build.ps1 -Clean           # 先清空 build/ dist/
powershell -ExecutionPolicy Bypass -File build.ps1 -SkipInstaller   # 只打包 exe
```

手动分步执行：

```bat
uv sync
uv run pyinstaller fee_app.spec --noconfirm --clean
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer.iss
```

产物：

| 路径 | 说明 |
| --- | --- |
| `dist\FeeMan\FeeMan.exe` | 免安装程序（onedir，含 `_internal` 依赖） |
| `dist\FeeMan-Setup-1.0.0.exe` | 安装包（约 10 MB，LZMA2 压缩） |

安装包会：

- 安装到 `%LOCALAPPDATA%\Programs\FeeMan`（`PrivilegesRequired=lowest`，无需管理员）；
- 可选在桌面创建快捷方式；
- 可选关联 `.cfee`：写入 `HKCU\Software\Classes\.cfee`，双击工程文件直接用本程序打开，并在「打开方式」列表中注册；
- 卸载时自动清理文件与注册表项，并刷新资源管理器图标缓存。

> 需要 Inno Setup 6：`winget install JRSoftware.InnoSetup`。语言文件已随仓库提供（`installer\Languages\`），不依赖安装目录自带中文。


## 功能

- **今日订餐**：打开即显示今天订餐人数（大号数字）、订餐与不订两份名单，以及今日单价与预计收入。今天是休息日或不在工程月份时会有对应提示。
- **工程管理**：新建 / 打开 / 保存 / 另存为 `.cfee` 工程（JSON 格式），标题、班级、核算年月、全月单价可随时修改。
- **命令行打开**：`python fee_app.py 路径.cfee` 直接载入工程；省略扩展名时会尝试补全 `.cfee`；文件不存在时退出码为 2。
- **每周休息日**：勾选周一～周日中不供餐的星期（默认周六、周日）。这些天单价恒为 0、不计入订餐天数，也不能单独设价或在「每日不订」中勾选。
- **每日单价**：全月统一单价之外，可单独为某一天设置价格（如加餐日）；可一键恢复为全月单价。
- **人员名单**：
  - 手动添加 / 编辑 / 删除；
  - 从 Excel(`.xlsx`) 或 CSV 导入，自动识别「学号 / 姓名 / 身份证 / 性别」表头；
  - 从文本粘贴导入（每行一人：`学号 姓名 [身份证] [性别]`）；
  - 下载名单模板。
- **身份证校验**：18 位校验码、出生日期合法性，可从身份证自动推导性别；无效者导入时跳过并给出提示。
- **每日不订**：选择人员后勾选不订日期；「标记今天不订」一键记录当天；「整月都不订」把当月每一天都标记为不订。
- **导入本月不订（自由文本）**：粘贴一整段格式不固定的通知，自动识别人员与餐别。
- **核算汇总**：按学号排序展示每人订餐天数、备注、应缴金额与总计，并导出 Excel 核算表。

> **没有“整月不订”这个独立标记。** 整月不订就是把当月每一个供餐日都写进该人的不订记录，因此和逐日不订完全等价：可以事后单独取消某几天，「不订天数」列会显示真实天数，换月后也不会自动沿用。旧工程里的 `month_opt_out` 字段在打开时会自动展开成逐日记录。

## 导入本月不订

「每日不订」页或「文件」菜单中打开，可粘贴或从 `.txt` 读取，支持如下写法：

```
1. 苏煜博，10月不订午餐
2. 44号范付璐10月不订午餐、晚餐、周六餐
3. 47号李华晨10月不订午餐、晚餐、周六餐
4. 41号陈心怡不订所有餐
5. 24号张家赫妈妈15566865321 10月份不订午餐、晚餐、周六餐
6. 39号王韵涵10月不订午餐、周六餐
7. 43号赵思琪10月不订晚餐
8. 7号张若衡妈妈 10月不订晚餐，周六餐
9. 40号 刘桐妤10月不定晚餐          ← “不定”同样识别
```

识别规则：

- **找人**：先按名单里的人名做穷举匹配（长名优先，`张三丰` 不会被 `张三` 抢走）；人名匹配不到才用行首“44号”按学号匹配。行首的 `7号` 未必是学号，因此人名优先。
- **餐别**：`午餐 / 午饭 / 中餐 / 午`、`晚餐 / 晚饭 / 晚`、`周六 / 星期六 / 周末餐`；`不订` 与 `不定` 均可。
- **全不订**：`所有`、`全部`、`全都`、`三餐`、`都`、`全天` → 全部餐别。
- **只订**：`只订午餐`、`仅订晚餐` → 取反，只有提到的餐是订的，其余都不订。
- **日期映射**：午餐、晚餐视为周一到周五；周六餐仅作用于周六。**某餐在本月没有对应日期时静默忽略**（例如周六本来就是每周休息日，`周六餐` 不会报错也不会生效）。
- 同一人多行会自动合并；行内找不到人或不含任何餐别关键词时，列出提示但跳过该行。

### 只记录选中的餐别

对话框顶部有三项勾选 **午餐 / 晚餐 / 周六餐**，默认全勾。

- 勾选 = 该餐别**可以**写进不订数据；**未勾选的餐别一律视为照常订餐**；
- 文本里提到未勾选的餐别时，会被直接丢弃、不记入不订记录；
- 例如只勾「晚餐」：文本写「不订午餐、晚餐」→ 只留下晚餐；写「不订午餐」→ 什么都不记录；
- 「所有 / 都 / 三餐」也只按勾选的餐别展开；
- 三项全勾：文本提到什么就记什么（默认行为）；三项全不勾：不会写入任何不订记录。

另有 **「覆盖这些人员的原有逐日不订记录」** 选项（默认不勾，即与原有记录合并）。

> 当前工程为「每天一个单价」：午餐、晚餐都落在同一个工作日上，任一餐不订即视为该工作日不订；周六餐对应周六。若需要按三餐分别计价，需要扩展成本模型。

## 导出过滤

「核算汇总」页右上角有 **“导出时不包括费用为 0 的人”**，默认勾选。

- 勾选时，导出 Excel 会剔除应缴金额为 0 的人员（整月不订、全月请假等），合计公式随之只统计实际导出的人；
- 该设置随 `.cfee` 工程持久化，旧工程打开时默认为勾选；
- 也可用 `export_settlement(proj, path, skip_zero=True/False)` 在代码中临时覆盖。


> 学号排序使用「自然排序」：数字段按大小比较，`1, 2, 10, 11` 而不是字典序的 `1, 10, 11, 2`；支持 `A1 / A2 / A10`、`2024-9 / 2024-10` 这类混合学号。名单页、每日不订人员列表、核算汇总与导出的 Excel 均使用同一顺序。

## 导出的核算表

四列版式：

| 班级 | 姓名 | 身份证号 | 费用 |
| --- | --- | --- | --- |
| 五年1班 | 宋雨泽 | 123456789023456789 | 187 |
| 五年1班 | 魏广震 | 123456789023456787 | 170 |
| … | | | |
| | | | `=SUM(D2:Dn)` |

- 四列：`班级 / 姓名 / 身份证号 / 费用`，首行为表头，无标题行、无边框、无填充；
- 末行仅费用列写入 `=SUM(D2:Dn)` 合计公式；
- 字体「等线 11」，身份证号列宽 20.25；
- `班级` 列取工程顶部的「班级」，留空时回退为工程名称。

## 今日订餐

程序启动后默认停在这一页，也可点「刷新」重新统计（切换到该页时自动刷新）。

- 顶部大号数字为**今天订餐人数**，后面补充「共 N 人，今天订餐 X 人、不订 Y 人；今日单价 a 元，预计收入 b 元」；
- 左侧「今日订餐」列出当天订餐人员的学号 / 姓名 / 性别；
- 右侧「今日不订」列出当天不订人员及原因（`今日不订` / `整月不订`）；
- 今天若为每周休息日，人数显示 0，全部人员列入「不订」并标注「每周休息日」；
- 今天若不属当前工程的年月，人数显示 `—` 并提示切换月份。

统计口径：`Project.eats_on(sid, day)` —— 该天供餐、且该天不在其不订记录中。对应接口还有 `diners_on(day)`、`diner_count(day)`、`non_diners_on(day)`。

## 成本口径

- 某人应缴 = 其实际订餐各天单价之和；
- 每周休息日价格为 0，既不计费也不计入订餐天数；
- 单价优先取当天单独设置，否则取全月单价。

## 工程文件

`.cfee` 为 UTF-8 JSON，包含 `format`（固定 `"cfee"`，加载时校验）、`version`、标题、班级、年月、单价、每周休息日 `skip_weekdays`（0=周一 … 6=周日）、导出过滤 `export_skip_zero`、日单价、名单与逐日不订记录 `skips`。不再写 `month_opt_out` 字段。

旧版工程（无 `skip_weekdays` 字段）打开时按默认「周六、周日休息」处理。
